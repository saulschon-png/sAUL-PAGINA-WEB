# Agricultura e Futuro Sustentável

## Tema da Página

Agricultura, inovação tecnológica, sustentabilidade e agronegócio do futuro, utilizando como conteúdo principal a produção de ovos jumbo e os fatores que influenciam seu tamanho.

---

## Objetivo da Página

Apresentar informações sobre a classificação dos ovos produzidos na avicultura, destacando:

- O que caracteriza um ovo jumbo;
- A influência da idade da galinha;
- Aspectos nutricionais da produção;
- Relação entre tecnologia, sustentabilidade e agricultura moderna.

Além disso, demonstrar uma interface moderna, responsiva e acessível para aplicações do setor agro.

---

## Funcionalidades

- Hero Section moderna
- Cards informativos
- Accordion expansível
- Área para 3 imagens locais
- Formulário de inscrição
- Área de comentários
- Modo escuro/claro
- Aumentar e diminuir fonte
- Leitura por voz com SpeechSynthesis API
- Botão para interromper leitura
- Layout responsivo com CSS Grid e Flexbox

## Como Utilizar

1. Salve os arquivos:
   - index.html
   - style.css
   - script.js

2. Coloque as imagens na mesma pasta:
   - Foto1.png
   - Foto2.png
   - Foto3.png

3. Abra o arquivo index.html em qualquer navegador moderno.

4. Utilize a caixa de acessibilidade para:
   - aumentar fonte;
   - diminuir fonte;
   - alternar tema;
   - iniciar leitura por voz;
   - parar leitura.
